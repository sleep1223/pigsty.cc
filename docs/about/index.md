# 关于 Pigsty

> Pigsty 是一个开箱即用的开源 PostgreSQL 全家桶发行版，致力于把世界上最先进的开源关系型数据库带入全盛状态。
> 本节汇总和项目本身相关的信息：功能、历史、协议、社区、商业服务。
